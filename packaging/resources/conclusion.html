Next step: add the printer.

  1. Open System Settings > Printers & Scanners.
  2. If the HL-3070CW is already in the list, select it and remove it.
  3. Click Add Printer, Scanner or Fax and choose the HL-3070CW.
  4. In Use, choose Select Software and pick Brother HL-3070CW native, then click Add.

If Brother HL-3070CW native is not in the list, Brother's driver files were not found: install Brother's driver for the HL-3070CW, then run this installer again. Until then you can use Brother HL-3070CW PostScript.

Help and updates: github.com/rolandzeiner/brother-hl3070cw-driver
