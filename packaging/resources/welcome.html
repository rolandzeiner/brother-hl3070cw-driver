This installs an open-source driver for the Brother HL-3070CW laser printer that runs natively on Apple Silicon and Intel Macs, without Rosetta.

It adds two drivers to the list you choose from when you add a printer:

  • Brother HL-3070CW, native driver (open source): prints like Brother's own driver. It needs the data files of Brother's macOS driver for this printer, which must be installed on this Mac. If you used the printer on this Mac before, it usually is.
  • Brother HL-3070CW, PostScript (BR-Script 3): works on every Mac, without Brother's files; the printer renders the pages itself, with somewhat weaker greys and colours.

This project is not made or endorsed by Brother.
