This installs an open-source driver for the Brother HL-3070CW laser printer that runs natively on Apple Silicon and Intel Macs, without Rosetta. It also supports nine printers with the same engine, untested.

It adds these drivers to the list you choose from when you add a printer:

  • Brother HL-3070CW, native driver (open source): prints like Brother's own driver. It needs the data files of Brother's macOS driver for this printer. If you used the printer with Brother's driver on this Mac before, they usually are here. They can also be added afterwards from Brother's package.
  • Brother HL-3070CW, PostScript (BR-Script 3): works on every Mac, without Brother's files. The printer renders the pages itself, with somewhat weaker greys and colours.
  • The native driver for the HL-3040CN, HL-3045CN, HL-3075CW, DCP-9010CN, MFC-9010CN, MFC-9120CN, MFC-9125CN, MFC-9320CW and MFC-9325CW, listed as native driver (open source, untested). They use the same data files. Only printing is supported, without fax and scanning.
