# Brother HL-3070CW driver for Apple Silicon

A native macOS (arm64 + x86_64) CUPS driver for the Brother HL-3070CW colour laser printer.

Brother's own macOS driver for this printer ships an Intel-only filter (`rastertobrother3040`)
that runs through Rosetta 2. Apple keeps Rosetta generally available only through macOS 27,
so the printer would stop working on later macOS versions. This project replaces that filter
with an open, native one.

## Status

**Beta.** Two drivers in one package:

| | Native driver (default) | PostScript driver (fallback) |
|---|---|---|
| How | this project's filter writes Brother's own printer language | the printer renders PostScript itself (BR-Script 3) |
| Needs | Brother's driver data on the Mac (see below) | nothing |
| Mono | byte-identical to Brother's driver | printer's own rendering |
| Colour | Brother's colour tables and halftones; about 99.96 % of dots identical to Brother's | printer's own rendering, visibly weaker greys and yellows |
| Options | paper sizes, tray / manual feed, media types, Colour / Mono / Auto, Color Mode (Normal, Vivid, None), Improve Gray, Toner Save, Improve Print Output | paper sizes, tray / manual feed, Colour / Mono, Toner Save |
| Not yet | Fine (2400 dpi class) | media types |

## Installing

The native driver uses Brother's halftone patterns, colour tables and ICC profiles. The
installer copies them from Brother's macOS driver package (5.0.0), so that package must be
installed once; its Intel filter is never run, so this works without Rosetta. Without it,
only the PostScript driver is installed. Brother's files are never part of this repository.

```sh
make                                   # builds build/rastertohl3070cw (Xcode command line tools)
./install.sh                           # asks for the admin password
./install.sh --queue MyPrinter         # also switch an existing printer queue to the native driver
./install.sh --queue MyPrinter --uri socket://192.168.1.20:9100   # create a queue
./install.sh --uninstall
```

Without `--queue`, add the printer in System Settings > Printers & Scanners and pick
"Brother HL-3070CW native" (or "Brother HL-3070CW PostScript") as the driver.

## How it works

The printer speaks Brother's host-based "XL2HB" language: PJL plus a small subset of HP's
documented PCL XL, carrying 1-bit K/C/M/Y bands in an undocumented compression format. That
format was worked out by black-box testing against Brother's own filter and is described in
[docs/FORMAT.md](docs/FORMAT.md). No Brother code is used or redistributed.


## Building and testing

```sh
make            # build/rastertohl3070cw, universal binary
make test       # compare with checksums of Brother's output (no Rosetta needed)
make oracle-test  # compare live with Brother's filter (needs its driver and Rosetta 2)
```

Run the filter by hand on a CUPS raster file:

```sh
build/rastertohl3070cw 1 user title 1 "BRMonoColor=Mono" page.ras > page.prn
```

## Repository layout

- `src/`: the CUPS filter (C): job writer and line encoder (`xl2hb.c`), halftoning (`halftone.c`),
  colour conversion (`color.c`)
- `ppd/`: the two PPD files, generated by `tools/genppd.py`
- `install.sh`: installer for macOS
- `tools/`: Python tools used to work out and check the format: raster writer, PCL XL parser,
  band decoder and encoder, measurement scripts, byte-for-byte comparison with Brother's filter
- `tests/fixtures.sha256`: checksums of Brother's output for `make test`
- `docs/FORMAT.md`: the printer language
